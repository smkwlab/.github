`@claude` メンションでの質問・助言（ワンショット）を有効化します。

- **助言のみ（read-only）**: `@claude` は回答と具体的な提案を返しますが、ファイルの編集・コミットは構造的に行えません（checkout もエージェントも無し）。修正は提案を見て本人が適用します。
- **ワンショット**: 質問と文脈（PR の diff・変更された `.tex` の全文・会話履歴）をまとめて 1 回の LLM 呼び出しで回答します。従来のエージェント方式（claude-mention）より高速・低コストです（smkwlab/.github#50 の実機比較に基づく移行）。
- 動作には org シークレット `ANTHROPIC_API_KEY` がこのリポジトリで利用可能である必要があります（未配布なら安全にスキップ）
- 起動するのは権限保有者（OWNER / MEMBER / COLLABORATOR）のコメントのみです
